# 唐代栏杆科普图校订

修订日期：2026-10-22（北京时间）。

## 结论

原图对栏杆防护、分隔空间等一般功能的说明大体可用，但将现代生成的雕花石栏直接放在唐代主题下，容易被误读为唐代原构或统一式样。现改为构造入门与证据辨别说明，插图明确标为艺术示意，不作唐代原状复原认证。

| 原图问题 | 修订 |
| --- | --- |
| 把望柱、寻杖、栏板、地栿写成唐代栏杆的一般固定组合 | 改用立柱、横向杆件及栏间构件描述；说明栏板及下部横材并非必有 |
| 将跨时期的构件称谓直接当作唐代统一定名 | 采用通用词，并说明望柱、寻杖、地栿等名称须结合时期与形制理解 |
| “地栿”等小字不清，构件引线部分不准确 | 正文重新排版；整体图仅保留三个清楚的通用标注，避免混乱细部引线 |
| 将繁复雕花、宝瓶或莲苞式柱头直接作为唐代实物形象 | 改为朴素构造艺术示意，不以生成图判定年代 |
| 以木石材料概括唐代不同建筑用途与等级 | 删除固定对应关系，要求核对具体实例和年代 |
| 将宝相花、卷草、云纹、如意纹等泛称唐栏常见纹样 | 收紧为莲花、卷草等相关题材举例；不作为唐代栏杆原样摹本 |
| 多处将盛唐审美、礼制等级与图中形式直接挂钩 | 改为功能和观察说明，不凭材质、雕花直接判定等级 |
| 外部为可见棋盘格 | 改为真实透明通道，内部纸色面板保留 |

## 用语与史实边界

- 本图保留栏杆的一般防护、围合、导向及立面组织功能；不保证所有具体栏杆同时具备完全相同的作用。
- “栏间构件”在此为便于入门理解的描述性用语，不冒充唐代专门定名。
- 寻杖、望柱、地栿等名称属于传统建筑术语，但跨时期、跨材料的使用不能直接等同于唐代统一构造规则。也不把宋代《营造法式》作为唐代制度的直接证明。
- “地栿”的栿为木字旁加伏，不应误作地袱、地杖。
- 不用木构榫卯的说明笼统解释所有石栏连接，也不以石栏雕刻繁复程度证明皇家等级。
- 壁画、石刻可提供图像信息，但不能仅凭画面颜色直接判断实际材料；艺术表现与真实尺度也须分别看待。
- 古建筑始建年代不自动等于现存栏杆年代；需辨别原构、替换、重修和现代补配。
- 本次属于术语、图文与表述边界校订，未对特定唐代栏杆开展断代、实测或考古报告逐项核验，也没有给现代示意图指定未经核实的唐代实例。正式出版或具体实例教学应补充对应资料。

延伸阅读可参考梁思成《中国建筑史》、傅熹年主编《中国古代建筑史》第二卷，以及相应实例的调查、考古或修缮报告。本处不是未经核验的直接引文或图源声明。
